
# FunkoFabs

> Onde cada colecionador encontra o Funko perfeito.

A **FunkoFabs** é um e-commerce desenvolvido para conectar colecionadores aos seus personagens favoritos, oferecendo uma plataforma simples, intuitiva e segura para compra de Funkos e outros colecionáveis.

- HTML
- CSS

# Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Catálogo de produtos
- Pesquisa de Funkos
- Carrinho de compras
- Finalização de pedidos
- Histórico de compras
- Gerenciamento de estoque
- Painel administrativo

---

# Organização

A equipe utiliza a metodologia **Scrum**, realizando o gerenciamento do projeto através de sprints, divisão de tarefas e versionamento utilizando Git e GitHub.

# Missão

Nossa missão é tornar a experiência de comprar Funkos tão divertida quanto colecioná-los.
