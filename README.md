# FunkoFabs

> **Onde cada colecionador encontra o Funko perfeito.**

A **FunkoFabs** é um e-commerce desenvolvido para conectar colecionadores aos seus personagens favoritos, oferecendo uma plataforma simples, intuitiva e segura para compra de Funkos e outros colecionáveis.

# Como executar o projeto

## Pré-requisitos

- Java 17 ou superior
- Maven
- PostgreSQL
- Git

## Clonando o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

## Backend

```bash
cd backend
./mvnw spring-boot:run
```

ou

```bash
mvn spring-boot:run
```

## Frontend

Abra o projeto no VS Code e execute utilizando o Live Server ou outro servidor HTTP de sua preferência.
